# DFUUtility 0.10.4 Community release candidate

DFUUtility 0.10.4 is a minimal maintenance release suitable for validating
the binary GitHub Release self-update workflow.

It retains the existing installation-provenance selection, exact redirect
policy, verified download, transactional installer, rollback, relaunch, and
post-launch verification behavior. The real 0.10.3 → 0.10.4 self-update has
not yet been performed or accepted.

Community artifacts are ad-hoc signed and are not Developer ID authenticated
or notarized.
