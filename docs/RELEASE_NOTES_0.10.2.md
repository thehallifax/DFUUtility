# DFUUtility 0.10.2 Community release candidate

DFUUtility 0.10.2 is a minimal maintenance release for validating the
GitHub Release binary-update workflow introduced in the 0.10.x series.

The distribution artifact retains explicit installation provenance and the
existing verified download, transactional replacement, rollback, relaunch,
and source-updater safety behavior. The real 0.10.1 → 0.10.2 self-update has
not yet been performed or accepted.

Community artifacts are ad-hoc signed and are not Developer ID authenticated
or notarized.
