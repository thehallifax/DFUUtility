# DFUUtility 0.10.6 Community release candidate

DFUUtility 0.10.6 is a minimal maintenance release intended to validate the
corrected binary self-update lifecycle shipped in 0.10.5.

The release retains the originating-process handoff wait, unique backup paths,
distinct destination-process relaunch verification, and post-relaunch result
semantics. The real 0.10.5 → 0.10.6 production self-update has not yet been
performed or accepted.

Community artifacts are ad-hoc signed and are not Developer ID authenticated
or notarized.
